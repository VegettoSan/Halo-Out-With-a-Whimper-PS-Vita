# Private inputs and asset distribution

## Do not add to this public repository
- Original HOWaW ZIP, EXE, external MP3 or later game data packs.
- Sprites, sounds, textures, room data, recovered GML, dumped scripts or embedded binary data from the executable.
- Proprietary Sony, Microsoft or GameMaker SDK components; private tool binaries; unauthorized third-party source.
- Secrets, credentials, local personal file paths, raw logs revealing system details.
- Complete VPKs containing copyrighted assets without documented distribution permission.

Store such materials only in Git-ignored original/, recovered/, local-tools/, private/, reports/local/ or build/. Inspect `git status --short` and `git diff --cached --name-only` before every commit.

## Allowed initially
- Original research notes, source-independent build instructions, first-party audit scripts, lawful compatibility shims written for this project, sanitized test metrics and neutral references to external projects.
- Short original technical observations and hashes may be committed.

This policy applies even if the repo later becomes private. Reconsider licenses, rights, attribution and packaging *before* any game release. No public redistributable data extractor is authorized by this document.
