The private native build extracts only cached GXM shader program data from the
installed SDL2 archive. No SDL renderer or runtime is linked. The authored
adapter is in vertex_tint.c; SDL binaries are not committed to this repository.
Source reference: https://github.com/libsdl-org/SDL/tree/SDL2/src/render/vitagxm
